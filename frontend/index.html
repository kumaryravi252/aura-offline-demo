YOUR 3-MINUTE WALKTHROUGH

Show the reasoning, step by step.

  1. Unstructured street. Explain the six classes, track IDs, predicted paths, and risk grid.
  2. Human vs animal. Pause and raise the horizon. The animal’s envelope grows faster because of the configured uncertainty prior.
  3. Hidden pedestrian. Between 3 and 4.5 seconds the pedestrian is unobserved. Pause and toggle memory to compare risk.
  4. Clear road. Show CONTINUE after the 0.8-second caution release. Switch to crossing to demonstrate SLOW / STOP.
  5. Offline proof. Disconnect Wi-Fi while this local app is running. Scenario reasoning continues.

Real camera / video mode

Install optional dependencies and place your model weights locally before the presentation. Start the server with python server.py --model models/yolo11n.pt --source road.mp4. See README for setup.

The built-in mode uses synthetic detections. Optional vision uses local YOLO, a manual corridor, and uncalibrated image coordinates; it does not estimate physical depth or steer a vehicle. Standard models do not have dedicated autorickshaw or thela classes.
